# Building a Guardrailed LLM Trading Risk-Manager Agent for AAPL

## Introduction
In this article, we build a guardrailed LLM-powered trading risk-manager agent for AAPL using DeepSeek. The agent dynamically adjusts position sizing based on real-time regime detection and risk metrics, combining walk-forward optimisation (WFO) with an out-of-sample backtest from 2023. The strategy integrates momentum signals, volatility filters, and an LLM-based guardrail layer to constrain decisions within predefined risk boundaries.
